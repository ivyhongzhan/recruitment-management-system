05 — RESEARCH / ENGINEERING NOTES

The assumptions
are part of
the interface.

A useful analytical tool should allow readers to question a measure—not just view a polished chart.

A / DATA PROVENANCE

Fixed-seed simulation

360 synthetic applications generated by data/generate.py (seed 20261105), across 4 departments, 5 source channels, and 4 cohorts. All distributions are deliberately invented.

B / METRIC DEFINITION

Ever-reached, not conversion

A record counts as reaching stage S when its highest recorded stage is S or later. Rates divide by applications in the current subset; these are retrospective stage-reach fractions, not individual selection probabilities.

C / DESIGN STATUS

Prototype, not validated product

Interaction flows support exploration and drill-down. No participant study, user testing, accessibility audit, fairness evaluation, or predictive model is claimed. Candidate decisions are not automated.

D / SYSTEM IMPLEMENTATION

Inspectible by design

Static site with a fully documented read-only FastAPI + SQLite API. Data generation, filtering, endpoint tests, and browser-compatible aggregation logic are included in the source package.
